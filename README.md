# 🚀 Unnecessarily Animated App List — NEXUS APP GALAXY

An **unnecessarily complex, fully 3D, gamified** Three.js page that turns a software list into an interactive galaxy experience.

![NEXUS APP GALAXY Screenshot](https://github.com/user-attachments/assets/73cb5310-b5f7-4545-bcbd-cc07cd05af85)

## ✨ Features

| Feature | Description |
|---|---|
| 🌌 **3D Galaxy** | 7 category planets orbiting a central Nexus Hub |
| 🪐 **76 App Nodes** | Every app floats as an orbiting sphere around its planet |
| 💫 **Bloom FX** | UnrealBloomPass post-processing for glowing neon lights |
| 🎮 **Gamification** | Score, combo multiplier (×10), 20 achievements |
| 📊 **Progress Bars** | Per-category discovery progress in sidebar |
| 🔍 **Search** | Live search that dims non-matching apps |
| 🏷 **Platform Filter** | Filter by All / Mac / Windows / Multi-platform |
| 🎢 **Auto-Tour** | Space-bar auto-tour flies through all 7 categories |
| 🖱 **Hover Tooltips** | Hover any planet or app for instant details |
| 📡 **Connection Lines** | Live lines drawn from hub to each orbiting planet |
| ⭐ **Star Field** | 6 000 animated twinkling stars + nebula clouds |
| 🎯 **Camera Fly-To** | Click a planet → smooth cinematic zoom |
| ⚡ **FPS Counter** | Real-time frame rate display |
| ⌨️ **Keyboard Shortcuts** | `1-7` jump to category, `Space` tour, `ESC` reset |
| 🏆 **20 Achievements** | Category masters, combos, score milestones, platform badges |

## 🎮 Controls

| Control | Action |
|---|---|
| **Click** planet | Fly to category, view all apps |
| **Click** app node | Discover app, earn score |
| **Drag** | Orbit the camera around the galaxy |
| **Scroll** | Zoom in / out |
| **`1`–`7`** | Jump directly to a category |
| **`Space`** | Toggle auto-tour |
| **`ESC`** | Return to full galaxy view |

## 🚀 Usage

Just open `index.html` in any modern browser — no build step required.

> Requires a browser with WebGL and ES module importmap support (Chrome 89+, Firefox 108+, Safari 16.4+).
